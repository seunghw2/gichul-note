# 4지선다 보기 → OX 시범 (10문항)

- 보기 하나를 OX 문장 하나로. 정답은 원본 공식 정답에서 그대로(틀린 것 고르기 → 정답 보기 X·나머지 O / 맞는 것 고르기 → 정답 보기 O·나머지 X).
- 단어만 있는 보기는 문제 문장과 합쳐 문장으로 만듦. 기존 변형 OX와 내용이 같으면 새로 만들지 않음.
